# Calculadora de Salário CLT

Aplicação web simples para estimar o salário líquido de um trabalhador CLT no Brasil.

Não é necessário instalar dependências ou configurar um servidor

Os cálculos usam as tabelas brasileiras de INSS e IRRF de 2026. A simulação considera salário mensal fixo, dependentes e outros descontos informados manualmente. Não contempla automaticamente adicionais, horas extras, faltas, pensão alimentícia, benefícios, múltiplos vínculos, 13º salário ou particularidades de convenções coletivas. O FGTS aparece como informação separada e não entra no total de descontos do empregado.

Esta ferramenta é uma estimativa educativa e não substitui o holerite nem o cálculo do departamento pessoal.

## Fontes oficiais

- INSS — Tabela de contribuição mensal: https://www.gov.br/inss/pt-br/direitos-e-deveres/inscricao-e-contribuicao/tabela-de-contribuicao-mensal
- Receita Federal — Tributação de 2026: https://www.gov.br/receitafederal/pt-br/assuntos/meu-imposto-de-renda/tabelas/2026
